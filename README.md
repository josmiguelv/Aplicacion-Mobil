# Pollos B3 — Aplicación móvil Android

Código fuente de la aplicación móvil de Pollos B3, mantenido por INTEGRA B2G.

## Estado

Repositorio inicializado. El proyecto Android previo V9/APK aún **no está importado** aquí. El desarrollo en Jetpack Compose parte de una base nueva, sin afirmar equivalencia funcional con el APK anterior.

Se trabajará por ramas y pull requests; no subir llaves privadas, credenciales ni datos reales sin autorización.

## Identidad y contenido

El logotipo oficial y fotografías del catálogo deben añadirse como archivos originales (no recreaciones). Productos, locales, precios y promociones reales se obtendrán de una API comercial cuando esté disponible. Mientras tanto, la app mostrará estados vacíos explícitos.
